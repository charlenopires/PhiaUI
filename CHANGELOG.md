# Changelog

All notable changes to PhiaUI are documented here.

## 0.1.0 — Unreleased

### Added

- Bootstrap Mix project with `ClassMerger`, `ComponentRegistry`, and `TemplateLinter`
- TailwindCSS v4 theme (`priv/static/theme.css`) with OKLCH palette, radius scale, shadow scale
- PrimitiveComponents: `Button`, `Card`, `Badge`, `Table`, `Icon`
- FormIntegration: `Input`, `Textarea`, `Select`, `Form`, `TagsInput`, `ImageUpload`, `RichTextEditor`
- InteractiveComponents: `Dialog`, `DropdownMenu`, `Accordion`
- DashboardShell: `Shell`, `Sidebar`, `Topbar`, `MobileSidebarToggle`
- DashboardWidgets: `StatCard`, `MetricGrid`, `ChartShell`
- Mix tasks: `phia.install`, `phia.add`, `phia.list`, `phia.icons`
- Ejectable EEx templates for all components
